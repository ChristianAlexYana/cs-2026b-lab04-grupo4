# Uso de las imágenes de evidencia

Los archivos `e4_notas_y_traza.png`, `e5_comparacion.png` y
`pruebas_finales.png` son láminas generadas a partir de notas, trazas y
salidas verificadas. No son capturas directas de una terminal.

Para el informe, se pueden insertar directamente los diagramas
`agentes/trazas/<corrida>/trayectoria.png`, generados desde los JSONL. Si se
solicitan capturas de pantalla, tomar capturas reales de la terminal o del
editor al mostrar el código, las métricas y `pytest -q`.
